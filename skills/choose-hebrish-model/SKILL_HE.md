# בחירת מודל של Hebrish

Hebrish הוא פרויקט אישי של דניאל רוזהיל (hebrish.app): מודלי דיבור לאנגלית שמשולבות בה מילים
בעברית. ב-Hugging Face יש הרבה מודלים של Hebrish, ורובם ישנים ונשמרים לעיון. הסקיל הזה קורא את
**מלאי המודלים**, הרשימה האחת שאומרת אילו מודלים מתוחזקים, ובוחר ממנה.

## כללים לסוכן

- תמיד קראו את המלאי החי; לעולם אל תענו מהזיכרון. המודלים מאומנים מחדש לעיתים קרובות.
- המליצו רק על מודלים שה-`support` שלהם הוא `recommended`, אלא אם הצורך של המשתמש פוסל את כולם.
- כל מודל עדיין ניתן להורדה, ובקשות גישה למודלים הישנים עדיין מאושרות. אמרו זאת אם המשתמש מבקש
  אחד מהם, אבל המליצו בחום על המעודכנים: הם עדיין מאומנים, ולכן מזהים את אוצר המילים הרחב ביותר.
- מודל שה-`support` שלו הוא `related` (Fritter, Gefilte) הוא פרויקט נפרד, לא מודל של Hebrish.
  הזכירו אותו רק אם המשתמש רוצה אנגלית בלי עברית (Fritter) או כתב עברי (Gefilte).
- אל תצטטו נתוני דיוק. לתוצאות, הפנו ל-https://hebrish.app/benchmarks.

## 1. קריאת המלאי

```bash
curl -s https://hebrish.app/data/model-inventory.json
```

לכל רשומה ב-`models` יש:

| שדה | משמעות |
| --- | --- |
| `support` | `recommended` (מתוחזק, השתמשו באלה), `available` (להורדה כמו שהוא, מתעדכן לעיתים רחוקות או בכלל לא), `legacy` (הוחלף, ראו `successor`), `related` (פרויקט נפרד) |
| `state` | `active`, `work-in-progress`, `occasional`, `frozen`, `proof-of-concept`, `superseded` |
| `use_case` | `dictation`, `streaming-dictation`, `voice-commands`, `tts`, `accessory` |
| `platforms` | `android`, `linux`, `windows`, `macos`, `browser`, `gpu`, `low-power` |
| `in_apps` | היכן אפליקציות Hebrish מציעות אותו: `android`, `desktop`, או ריק |
| `current_version`, `last_release` | הגרסה האחרונה ותאריכה |
| `successor` | המודל שיש להשתמש בו במקום, עבור מודלים ישנים |
| `repo`, `page` | מאגר ה-Hugging Face והעמוד ב-hebrish.app |

## 2. שאלו רק מה שצריך

אם המשתמש לא אמר, שאלו:

1. לשם מה: הקלדה בקול (הכתבה), לראות את המילים תוך כדי דיבור (סטרימינג), פקודות קצרות למחשב או
   לטלפון (פקודות קוליות), או הקראת טקסט (טקסט לדיבור)?
2. איפה: טלפון Android, מחשב Linux או Windows, Mac, שרת GPU, או מכשיר קטן?
3. באפליקציית Hebrish, או בכלים של המשתמש עצמו (sherpa-onnx, NeMo, transcribe.cpp, llama.cpp)?

## 3. בחירה

סננו את `models` לפי `use_case` ו-`platforms`, השאירו `support` = `recommended`, והעדיפו מודל
שה-`in_apps` שלו מכסה את המכשיר של המשתמש אם הוא משתמש באפליקציית Hebrish. תוצאות אופייניות:

- הכתבה בטלפון או במחשב: **Sabich**, ברירת המחדל באפליקציות.
- הכתבה בסטרימינג ב-Linux או Windows: להמליץ על **Sabich**. Shakshuka (באפליקציית שולחן העבודה) מציג מילים תוך כדי דיבור, אבל הוא פחות מדויק ועדיין לא מומלץ; להזכיר אותו רק אם הסטרימינג חשוב יותר מהדיוק.
- פקודות קוליות: **Falafel** (0.6B למחשבים שולחניים, Falafel 110M לטלפונים ולמחשבים ניידים).
- טקסט לדיבור: **Meorav**, עם הכלים של המשתמש; לאפליקציות Hebrish אין טקסט לדיבור.

אם המשתמש מציין מודל ישן, תנו את ה-`state` וה-`successor` שלו והמליצו על היורש.

## 4. תשובה

תנו את שם המודל, למה הוא מתאים, את ה-`current_version` וה-`last_release` שלו, ואת הקישורים שלו
(`page` ו-`repo`). להורדת האפליקציות: https://hebrish.app/download. הטבלה המלאה:
https://hebrish.app/models/inventory.

# תיקון טעויות תמלול של Hebrish

Hebrish היא אפליקציית ההכתבה של דניאל רוזהיל, פרויקט אישי (hebrish.app). ה**מילון האישי** שלה הוא
רשימת חיפוש והחלפה שחלה על הטקסט של המודל אחרי הפענוח. רשומה מורכבת מ-`word` (איך זה צריך להיכתב,
ויכול להיות גם ביטוי או משפט שלם) ומביטויי `heard` (מה שהמודל כותב במקום). הסקיל הזה מוצא כללים טובים
ובודק אותם מול היסטוריית התמלילים האמיתית של המשתמש לפני שהוא מוסיף אותם.

## כללים לסוכן

- ה-API נמצא בכתובת `http://127.0.0.1:8723`, אלא אם המשתמש שינה את הפורט בהגדרות, Local API.
- אל תשלחו כותרת `Origin`: בקשות עם כותרת כזו נדחות (403).
- **הריצו תצוגה מקדימה לכל כלל לפני שאתם מוסיפים אותו.** תצוגה מקדימה לא כותבת כלום.
- זוג שהמשתמש ציין במפורש: הריצו תצוגה מקדימה, הוסיפו, דווחו על התוצאה. זוגות שמצאתם בעצמכם: הציגו
  את הטבלה משלב 3 והוסיפו רק מה שהמשתמש הסכים לו.
- כתבו מילים בעברית בתעתיק של המשתמש, אף פעם לא באותיות עבריות.

## איך ההתאמה עובדת

- אין הבדל בין אותיות גדולות לקטנות, רק מילים שלמות, וכל רצף רווחים או שורות חדשות מתאים לכל רצף אחר.
- מעבר לכך, כל ביטוי `heard` הוא **מילולי**: `my word prompts` לא מתאים ל-`my word, prompts`. הוסיפו
  את הצורה עם הפיסוק כביטוי שני אם ההיסטוריה מראה אותה. ביטוי יכול לעבור בין משפטים אם הוא כתוב עם
  הפיסוק שהמודל משתמש בו.
- `word` עם אות גדולה נכתב תמיד בדיוק כפי שהוזן.
- גם ה-`word` עצמו מתאים, כך שרשומה אחת מתקנת גם אותיות גדולות (`My Weird prompts`). המשמעות היא
  שרשומה `IT` הופכת כל "it" ל-"IT".
- ההתאמה הארוכה ביותר מנצחת, והחלפה לא מותאמת שוב.
- כשהכנסה תוך כדי דיבור (insert-as-you-go) פעילה, כל קטע מתוקן בנפרד, אז ביטוי שנחתך לשניים בהפסקה
  מפוספס. אי אפשר לפתור את זה מהמילון.

## 1. בדיקה שהשליטה פעילה

```bash
curl -s http://127.0.0.1:8723/health
```

`"control": true` אומר להמשיך. `"control": false`: בקשו מהמשתמש לפתוח את Hebrish, **Settings →
Local API**, ולסמן את *Let agents read history and control the app*. אין מפתח `control`: האפליקציה
ישנה מדי, השתמשו בסקיל `update-hebrish`. החיבור נדחה: Hebrish לא פועלת, או שה-API המקומי כבוי.

קראו מה כבר קיים, כדי לא להוסיף כפילויות:

```bash
curl -s http://127.0.0.1:8723/v1/dictionary
```

## 2. מציאת מועמדים

דלגו על השלב הזה אם המשתמש ציין את הזוג. אחרת חפשו בסדר הזה:

1. **התיקונים של המשתמש עצמו**, הראיה החזקה ביותר. `original` הוא הטקסט של המודל ו-`text` הוא מה
   שהמשתמש שינה אותו אליו. השוו ביניהם, ושמרו מה שחוזר:

   ```bash
   curl -s 'http://127.0.0.1:8723/v1/history?edited=1&limit=1000'
   ```

2. **גרסאות של מונח מוכר.** לשם שהמשתמש מזכיר, חפשו את חלקיו וקראו את המילים הסמוכות, כי `q` מתאים
   למילים, לא לשגיאות כתיב:

   ```bash
   curl -s -G http://127.0.0.1:8723/v1/history --data-urlencode 'q=prompts' -d limit=200
   ```

3. **דברים מוזרים בטקסט האחרון.** קראו את כמה מאות התמלילים האחרונים וחפשו ביטויים שלא הגיוניים
   בהקשר, ושם שנכתב בכמה צורות.

שמרו מועמד רק אם הוא חוזר. הופעה אחת היא טעות הקלדה, לא כלל.

## 3. תצוגה מקדימה לכל כלל

```bash
curl -s -X POST http://127.0.0.1:8723/v1/dictionary/preview \
  -H 'Content-Type: application/json' \
  -d '{"word": "My Weird Prompts", "heard": ["my word prompts"], "limit": 20}'
```

בתשובה יש `rows_scanned`, `rows_changed`, `replacements`, `by_source` (כל צורה שנמצאה, עם מספר
ההופעות) ו-`samples` (`id`, `before`, `after`, עם הקשר).

קראו את הדוגמאות ושפטו:

- **כל דוגמה היא תיקון:** שמרו.
- **חלק מהדוגמאות היו נכונות כפי שהיו:** הביטוי רחב מדי. האריכו אותו במילה סמוכה והריצו תצוגה מקדימה
  שוב. אף פעם אל תוסיפו כלל על מילה נפוצה לבדה (`word` → `weird`).
- **`rows_changed` הוא 0:** הביטוי לא נמצא בהיסטוריה. בדקו את הכתיב מול תמליל אמיתי. הוסיפו אותו רק
  אם המשתמש בטוח שזה קורה.
- **`by_source` מראה צורה שלא ציפיתם לה:** קראו את הדוגמה הזו. בדרך כלל זה ה-`word` שמתאים לצורה
  המפוצלת או באותיות קטנות של עצמו, וזה בסדר.

לכללים שמצאתם בעצמכם, הציגו למשתמש: הכלל, מספר השורות שישתנו, דוגמה אחת, והשיפוט שלכם.

## 4. הוספת הכלל

```bash
curl -s -X POST http://127.0.0.1:8723/v1/dictionary \
  -H 'Content-Type: application/json' \
  -d '{"word": "My Weird Prompts", "heard": ["my word prompts"]}'
```

הוספה ל-`word` קיים ממזגת את הביטויים ושומרת את הישנים (תשובה 200; מילה חדשה היא 201). היא חלה
מההקלטה הבאה, בלי הפעלה מחדש, ולשונית Dictionary מתעדכנת מעצמה.

כדי לבטל, מילה או ביטוי אחד בלבד:

```bash
curl -s -X DELETE -G http://127.0.0.1:8723/v1/dictionary \
  --data-urlencode 'word=My Weird Prompts' --data-urlencode 'heard=my word prompts'
```

השמיטו את `heard` כדי להסיר את המילה כולה.

## מגבלות

- תמלילים ישנים לא נכתבים מחדש. כללים חלים על טקסט חדש.
- כלל מתקן מילה שהמודל כותב לא נכון **ובעקביות**. אם הוא כותב משהו אחר בכל פעם, כל צורה צריכה ביטוי
  משלה, והתיקון האמיתי הוא אימון מחדש: אמרו למשתמש לשלוח את זה דרך <https://hebrish.app/feedback>.
- המילון של שולחן העבודה לא מסונכרן עם Android, שמשתמשת במילון האישי של הטלפון.
